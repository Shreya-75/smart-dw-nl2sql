# Notebooks

Exploratory analysis notebooks for the Olist Smart Data Warehouse project.

| Notebook | Description |
|---|---|
| `01_eda.ipynb` | Exploratory data analysis of raw Olist CSVs |
| `02_etl_validation.ipynb` | Post-ETL row counts and FK integrity checks |
| `03_agent_testing.ipynb` | Manual agent testing with example questions |

Run `jupyter notebook` from the project root to open.
